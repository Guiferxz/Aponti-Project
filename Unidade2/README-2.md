# Unidade 1 — Análise de Dados de Acidentes da PRF

## 📌 Sobre a atividade

Esta atividade da **Unidade 1** tem como objetivo trabalhar conceitos de análise e manipulação de dados utilizando uma base de acidentes rodoviários disponibilizada pela **Polícia Rodoviária Federal (PRF)**.

A atividade utiliza dados referentes aos acidentes registrados durante o ano de **2025**, permitindo realizar operações matemáticas, análises estatísticas, consultas de dados e representação gráfica das informações.

## 📊 Base de dados

A base principal utilizada é o conjunto de dados abertos da **PRF/DATATRAN 2025**, contendo informações sobre acidentes ocorridos em rodovias federais brasileiras.

Entre os principais campos utilizados estão:

- `id` — identificação do acidente;
- `data_inversa` — data da ocorrência;
- `dia_semana` — dia da semana;
- `horario` — horário do acidente;
- `uf` — estado onde ocorreu;
- `br` — rodovia;
- `km` — quilômetro da ocorrência;
- `municipio` — município;
- `causa_acidente` — causa associada ao acidente;
- `tipo_acidente` — tipo de acidente;
- `classificacao_acidente` — classificação quanto à existência de vítimas fatais;
- `tipo_pista` — tipo da pista;
- `tracado_via` — característica do traçado da via;
- `pessoas` — quantidade de pessoas envolvidas;
- `mortos` — quantidade de vítimas fatais;
- `feridos_leves` — quantidade de feridos leves;
- `feridos_graves` — quantidade de feridos graves;
- `ilesos` — quantidade de pessoas ilesas;
- `veiculos` — quantidade de veículos envolvidos.

## 📁 Organização da planilha

A atividade está dividida em diferentes abas, cada uma destinada a uma etapa da análise.

### 1. Dados da PRF

A primeira aba contém a base completa de dados dos acidentes registrados em 2025.

Essa base serve como fonte para as análises realizadas nas etapas seguintes.

### 2. Operações Básicas

Nesta etapa são utilizados registros específicos da base para realizar operações matemáticas e estatísticas básicas.

Foram trabalhados cálculos como:

- Índice de severidade;
- Número de sobreviventes;
- Média de pessoas envolvidas;
- Valores máximo e mínimo;
- Outras operações utilizando os dados dos acidentes.

O objetivo é utilizar fórmulas de planilha para extrair informações relevantes a partir dos dados disponíveis.

### 3. Parte 2 — Estatística

Nesta aba são realizadas análises estatísticas utilizando principalmente a variável `mortos` e informações relacionadas às rodovias e municípios.

Entre os cálculos realizados estão:

- Média de mortos;
- Total de mortos;
- Contagem de ocorrências;
- Quantidade de municípios;
- Mediana;
- Quartil;
- Valor mais frequente;
- Análise de mortes por rodovia.

Essas operações permitem compreender melhor a distribuição dos acidentes e das vítimas fatais na base analisada.

### 4. PROCV e Gráficos

A última etapa trabalha a função **PROCV**, permitindo localizar informações específicas na base de dados a partir de um determinado identificador.

Foram utilizadas informações como:

- ID do acidente;
- UF;
- Causa do acidente;
- Tipo de acidente;
- Número de mortos.

Além disso, a atividade aborda a criação de **gráficos**, permitindo representar visualmente os dados e facilitar a interpretação dos resultados.

## 🎯 Objetivos

A atividade tem como principais objetivos:

1. Trabalhar com uma base de dados real;
2. Aprender a organizar e manipular informações em planilhas;
3. Aplicar operações matemáticas e estatísticas;
4. Utilizar funções de busca, como o PROCV;
5. Analisar informações relacionadas aos acidentes rodoviários;
6. Criar gráficos para facilitar a visualização dos resultados;
7. Desenvolver a capacidade de interpretar dados e transformá-los em informações úteis.

## 🛠️ Ferramentas utilizadas

- **Google Sheets / Microsoft Excel**
- Base de dados aberta da **Polícia Rodoviária Federal (PRF)**
- Fórmulas e funções de planilha
- PROCV
- Operações estatísticas
- Gráficos

## 📈 Resultado

A atividade possibilita transformar uma grande quantidade de registros de acidentes em informações organizadas e analisáveis.

Por meio das operações básicas, cálculos estatísticos, consultas com PROCV e gráficos, é possível identificar padrões relacionados aos acidentes, suas causas, tipos, localização e quantidade de vítimas.

Dessa forma, a Unidade 1 proporciona uma introdução prática à **análise de dados**, utilizando uma situação real e uma base de dados pública.
